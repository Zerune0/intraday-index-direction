# 可解释日内信号与股指方向预测

简体中文 | [English](README.md)

本仓库保存研究项目 **《可解释日内信号与实时开盘至收盘方向预测：来自中国股票指数的证据》** 的分析代码。

本项目研究截至13:30可观测的日内价格形态和突破信号，能否帮助判断中国主要股票指数相对于当日开盘价的收盘方向。研究比较了确定性规则基准与Logistic回归，并进行了按时间划分的留出集检验、滚动验证和外部指数验证。

## 仓库内容

- `intraday_index_direction_refactored.py`：以提高可读性和可维护性为目标的最终分析代码。
- `intraday_index_direction_submission.py`：为保留来源与修改记录而保存的原始分析代码。
- `requirements.txt`：完成验证运行时所使用的Python软件包及其确切版本。
- `data/README.md`：在不分发原始数据的前提下，说明私有数据的目录结构、文件命名方式和必需字段。
- `.gitignore`：阻止受限数据、生成结果、论文材料、密钥和本地缓存被提交到仓库。

优化版对重复操作进行了整理，集中管理常量，使用明确的输出路径，并加入受保护的 `main()` 程序入口。它没有改变研究目标、特征、样本划分、模型设定、预测阈值、随机种子或论文报告结果。经过验证，原版和优化版生成的43个输出文件完全一致。

## 数据可用性

分钟级原始数据通过MyQuant获得。由于尚未确认再分发许可，本仓库不提供这些数据。分析代码要求在Python脚本同级目录下存在以下三个本地数据文件夹：

```text
1-沪深300数据/
2-上证指数数据/
3-深证成指/
```

每个文件夹应包含2015–2025年的年度CSV文件，并遵循代码中使用的文件命名规则。使用者必须自行取得具有适当许可的数据，并按照代码要求准备字段结构。

## 环境配置

经过验证的运行环境使用Python 3.13。建议在独立虚拟环境中安装记录的依赖：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 运行分析

将具有适当许可的输入文件放入对应目录后，运行最终版本：

```bash
python intraday_index_direction_refactored.py
```

生成的文件将保存至 `analysis_outputs_refactored/`。原始投稿版本的输出目录为 `analysis_outputs/`。
